# sculpt.no

A new website for Sculpt, Ester Svindland's studio in Flekkefjord, Norway,
which makes pregnancy sculptures and other personal sculptures of real people,
3D scanned and finished by hand. The current site is
[sculpt.no](https://www.sculpt.no). This one runs as a preview at
[polybjorn.github.io/sculpt-no](https://polybjorn.github.io/sculpt-no/).

## How it works

Built with [Astro](https://astro.build) as static HTML and plain CSS. Three
small scripts open the menu on phones, add arrow buttons to the photo strip on
the front page for a mouse, and open a gallery photo whole. Without them the
menu is listed in full, the strip still scrolls and the gallery shows its
cropped photos.

The text is Ester's own, carried over from the current site. A test compares
every built page with the original text, and each change from it is listed with
the old and new wording for her to approve. Every page keeps its old address or
redirects to the page that took it over, so existing links and search results
still land.

Fonts and photos are served from the site itself, so a visit loads nothing from
any other domain.
