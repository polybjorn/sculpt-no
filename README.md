# sculpt.no

A new website for Sculpt, Ester Svindland's studio in Flekkefjord, Norway,
which makes pregnancy sculptures and other personal sculptures of real people,
3D scanned and finished by hand. The current site is
[sculpt.no](https://www.sculpt.no). This one runs as a preview at
[polybjorn.github.io/sculpt-no](https://polybjorn.github.io/sculpt-no/).

## How it works

Built with [Astro](https://astro.build) as static HTML and plain CSS. Two small
scripts open the menu on phones and add arrow buttons to the photo strip on the
front page for a mouse. Without them the menu is listed in full and the strip
still scrolls.

The text is Ester's own, carried over word for word from the current site, and
every page keeps its old address, so existing links and search results still
land. A test compares every built page with the original text.

Fonts and photos are served from the site itself, so a visit loads nothing from
any other domain.
